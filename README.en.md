# HomeSolution: Connect technicians and clients in real time

[![License](https://img.shields.io/badge/License-Proprietary-red.svg)](LICENSE)
[![ES](https://img.shields.io/badge/Spanish-version-green.svg)](./README.md)

**An Uber-style mobile app for home services. Find qualified technicians near you, in minutes.**

## What problem does it solve?

Finding a trusted technician is hard. Prices are not transparent. You don't know who is available nearby. Qualified technicians have no platform to offer their services.

**HomeSolution connects supply and demand in real time.**

## What does it do?

| Feature | Description |
|---------|-------------|
| Geolocation | Shows nearby technicians in real time |
| Ratings and reviews | Transparent reputation system |
| Built-in chat | Instant coordination |
| Secure payments | Stripe / MercadoPago |
| Technician verification | Certifications and profile validation |
| Service history | Complete record of jobs |
| Multi-categories | Plumbing, electrical, programming, design, etc. |
| Push notifications | Real-time alerts |

## Who is it for?

- **Users**: need a fast, reliable technician with clear pricing.
- **Technicians**: want to find clients without paying abusive commissions.
- **Service companies**: can manage their workforce.

## Architecture

| Layer | Technology |
|-------|------------|
| Mobile frontend | React Native / Flutter |
| Backend API | Node.js + Express |
| Database | PostgreSQL |
| Authentication | JWT |
| Geolocation | Google Maps API |
| Payments | Stripe / MercadoPago |
| Notifications | Firebase Cloud Messaging |
| Real-time chat | WebSockets (Socket.io) |
